🔧 CORREÇÕES APLICADAS

Erro Encontrado:
  ❌ "SyntaxError: Unexpected token '<', "<!doctype""
  ❌ "Cannot render <Router> inside another <Router>"

Diagnóstico:
  • App.tsx tentava carregar './src/routes.json'
  • Vite não serve arquivos de src/ via fetch
  • Retornava HTML 404 em vez de JSON
  • Parser falhava → routes undefined
  • BrowserRouter + Routes → erro de router aninhado

Solução Aplicada:
  ✓ Mover routes.json para public/
  ✓ Atualizar path em App.tsx para '/routes.json'
  ✓ Limpar cache Vite
  ✓ Rebuild e testar

Resultado:
  ✓ Build funciona
  ✓ Dev server funciona
  ✓ Routes carregam corretamente
  ✓ Menu renderiza sem erros
